USAGE 使い方

本ページに USAGE.md の内容を反映しています。該当セクションへはヘッダーのナビから移動できます。

1. インストールと起動

必要なもの

  • Node.js v20 以上
  • pnpm v9 以上（npm install -g pnpm で導入）

セットアップ

git clone https://github.com/watanabe3tipapa/bookmark-manager-pe.git
cd bookmark-manager-pe
pnpm install

pnpm install の最後に、SQLite 用のネイティブモジュールが Electron 向けに自動ビルドされます。

起動

pnpm dev

初回は数秒かかりますが、アプリのウィンドウが開きます。

2. 画面の見方

画面は 3 つのパネル で構成されています。

パネル場所役割
サイドバー左検索・スマートビュー・タグ・デバイススコープ・同期
ブックマーク一覧中央絞り込んだブックマークの一覧と操作ボタン
詳細パネル右1件のブックマークの編集・タグ操作

中央の一覧でブックマークをクリックすると右に詳細パネルが開き、タイトル・URL・メモの編集やタグの追加・削除ができます。

3. 基本操作

ブックマークを追加する

「追加」ボタンをクリック

一覧上部にあります。

URL を入力

タイトル・タグは省略可能です。

Enter で保存

ブラウザのブックマークをインポートする

各ブラウザで HTML ファイルを書き出して、アプリの インポート ボタンから取り込みます。

ブラウザ別のエクスポート手順
  • Chrome: ブックマークマネージャ（Cmd + Option + B）→ ⋯ → ブックマークをエクスポート
  • Firefox: ライブラリ（Cmd + Shift + O）→ インポートとバックアップ → HTML 形式でエクスポート
  • Safari: ファイル → ブックマークを書き出す
  • Edge: お気に入りの管理 → ⋯ → お気に入りをエクスポート
ポイント フォルダ構造は自動的に「タグ」として取り込まれます。複数のブラウザから順番にインポートして全部を1箇所に集められます。インポートしてもブラウザ側のデータは一切変更されません。

削除・タグ編集

  • 詳細パネルからタイトル・URL・メモの編集、タグの追加・削除、削除ができます。
  • 一覧の行に表示されたタグの × を押すと、そのタグだけ外せます。

4. 検索

サイドバー上部の検索ボックスに入力すると、タイトル・URL・タグ を横断検索します。検索中もスマートビューやタグフィルタはそのまま適用されます。

5. 整理機能

スマートビュー（サイドバー上部）

ビュー内容
すべて全ブックマーク（デフォルト）
未分類タグが1つも付いていないもの
最近追加7日以内に追加したもの
使われていない追加から30日以上経過し、一度も開いていないもの
よく見る訪問回数が多いもの

タグフィルタ / デバイススコープ（サイドバー）

タグをクリックするとそのタグの付いたものだけに絞り込み。スコープは「すべて / 共有のみ / デバイス固有のみ」を切り替えられます（詳細パネルで各ブックマークも切替可）。

重複検出・マージ

  1. 一覧上部の 重複 ボタンをクリック
  2. 検出された重複グループを確認
  3. グループ単位で マージ またはスキップを選択

URL は自動正規化（utm_* 等の広告パラメータを除去）して比較するため、実質同じページは確実に重複判定されます。

マージ時の統合ルール
項目ルール
タイトル一番長いタイトルを採用
タグ両方のタグを合体
訪問回数合算
メモ改行で連結

6. 探索機能（AI 要約・サムネイル・リンク発見）

Cloudflare のブラウザ（Kitesurf）で、保存したブックマークを自動分析します。日本語で 2〜3 文の AI 要約、サムネイル保存、関連リンクの発見を行います。

事前準備（1回だけ）

この機能は Cloudflare Worker として動くため、まずデプロイが必要です。

cd workers/explore
pnpm install
npx wrangler login    # 初回のみ（Cloudflare アカウント）
npx wrangler deploy

成功すると https://bookmark-explore.xxxxx.workers.dev のような Worker URL が表示されます。

使い方

「探索」ボタンをクリック

アプリの一覧上部にあります。

Worker URL を設定

パネル内の「設定」→ 接続テスト → 保存。

対象を選択

デフォルトは「未分類のみ」。全件 / 現在の絞り込みも選択可。

「探索を開始」

完了後、結果の「適用」で要約・タグ・サムネイルを保存。

関連リンクを追加

「発見したリンク」から未登録のページをまとめて登録。

注意 Kitesurf はベータ版のため、動画・ログイン必須サイト・ボット対策サイトでは失敗する場合があります（そのブックマークだけ失敗扱いになり、探索は続行）。対象件数が多いと時間がかかるため、まずは「未分類のみ」から試すのがおすすめです。

7. Zed AI 連携（高度な整理）

AI パネルを開く

一覧上部の「AI」ボタン。

API サーバを起動

パネルの「起動」で http://localhost:9876 が起動。

プロンプトをコピー

タグ分類 / タイトル正規化 / 重複マージ提案 / コレクション分析。

Zed で実行

AI チャット（Cmd + I）に貼り付け、生成された JSON をパネルで適用。

8. GitHub 同期（複数デバイス）

セットアップ

PAT を発行

GitHub → Settings → Developer settings → Personal access tokens (classic)。スコープは repo。

同期用リポジトリを作成

公開・非公開どちらでも可。

アプリで設定

サイドバー下部「同期」→ トークン / 所有者 / リポジトリ名 / デバイス名 → 接続テスト＆保存。

同期ボタン をクリックすると、取得 → マージ → 送信 → 結果通知が自動で行われます。

コンフリクト（競合）が起きたら

選択肢動作
ローカルを保持このデバイスの内容を残す
リモートを採用GitHub 上の内容で上書き
自動マージタイトル・タグ・メモを統合
スキップ今回は保留して、後でまた同期

9. データの場所とバックアップ

OS保存場所
macOS~/Library/Application Support/bookmark-manager-pe/bookmarks.db
Windows%APPDATA%/bookmark-manager-pe/bookmarks.db
Linux~/.config/bookmark-manager-pe/bookmarks.db

バックアップはアプリを終了した状態で bookmarks.db をコピーするのが確実です。GitHub 同期を設定していればリポジトリ内にもデータが残るため二重に安全です。
