ブックマークを、
ひとつの場所に。

Chrome・Firefox・Safari・Edge のブックマークをまとめて取り込み、 AI が自動で要約・タグ付け。GitHub 同期でどのデバイスからでも同じコレクションにアクセスできます。

6つの機能でコレクションを整頓

保存するだけのブックマーク管理から、次のステージへ。

📥

マルチブラウザ取り込み

各ブラウザの HTML エクスポートを一括インポート。フォルダ構造は自動的にタグへ変換されます。

👁️

スマートビュー

未分類・最近追加・使われていない・よく見る。目的別のビューとデバイススコープで必要なものだけを表示。

🧹

重複検出・マージ

URL を自動正規化して重複を検出。タイトル・タグ・メモをルールに基づいて安全に統合します。

🤖

AI 探索（Kitesurf）

Cloudflare のブラウザでページを分析。日本語の AI 要約・サムネイル・関連リンクを自動取得。

✨

Zed AI 連携

エディタの AI を使って高度なタグ分類・タイトル整形・コレクション分析。生成した JSON をワンクリックで適用。

🔄

GitHub 同期

リポジトリ経由で複数デバイス間を同期。競合が起きてもサイド・バイ・サイドの解決 UI で安全にマージ。

3ステップで始められる

インストールから自動整理まで、5分もかかりません。

インストール

Node.js と pnpm があればすぐに起動できます。

pnpm install && pnpm dev

ブックマークを取り込む

ブラウザの HTML エクスポートをインポートするだけ。フォルダはタグになります。

AI で自動整理

未分類ビューから探索を実行。要約・タグ・サムネイルが自動で付き、関連リンクも発見。

すっきり3パネル構成

検索・タグ・スマートビューのサイドバー、一覧、詳細編集をひとつの画面に。

左: サイドバー / 中央: ブックマーク一覧 / 右: 詳細パネル
